# 관리자 요청서 전체 목록 조회 API 테스트

- 도메인: 견적·매칭
- 결과: 통과
- 관련: #151

## 확인 범위

- `GET /api/admin/requests`: ADMIN 전용 요청서 전체 목록
- CLOSED 요청서와 24시간이 지난 요청서까지 포함되는지
- status 필터, 페이징, 정렬(id, createdAt, requestStatus)
- 관리자가 아니거나 잘못된 파라미터일 때 거절
- 작성자, 카테고리, 지역 조회에서 N+1이 생기지 않는지

## 확인 결과

| # | 요청 | 기대 | 결과 |
| --- | --- | --- | --- |
| 1 | 전체 (pageSize=20) | 200, 10개 최신순, CLOSED(6)와 만료 요청서(9·10) 포함 | 통과 |
| 2 | status=CLOSED | 200, 요청서 6만 | 통과 |
| 3 | pageNumber=2, pageSize=3 | 200, 4~6번째(7·8·1), totalPages 4 | 통과 |
| 4 | sortBy=id, sortOrder=asc | 200, 1·2·3 순서 | 통과 |
| 5 | 고객 토큰 | 403 | 통과 |
| 6 | sortBy=price | 400 정렬 조건 오류 | 통과 |
| 7 | status=DONE | 400 타입 오류 | 통과 |
| 8 | SQL 로그 | 목록 조회는 join select 1번, 필요할 때만 count 1번 | 통과 |

## 재현 명령과 응답

```bash
login() { curl -s -X POST "$BASE/api/public/auth/login" -H "Content-Type: application/json" \
  -d "{\"email\":\"$1\",\"password\":\"1234\"}" | tr -d '\n' | sed -E 's/.*"accessToken" *: *"([^"]+)".*/\1/'; }
A=$(login admin1@example.com); C=$(login customer1@example.com)

curl "$BASE/api/admin/requests?pageSize=20" -H "Authorization: Bearer $A"
# → 200, totalElements 10, 첫 항목 requestId 4

curl "$BASE/api/admin/requests?status=CLOSED" -H "Authorization: Bearer $A"
# → 200, [{ "requestId": 6, "requestStatus": "CLOSED", ... }]

curl "$BASE/api/admin/requests?pageNumber=2&pageSize=3" -H "Authorization: Bearer $A"
# → 200, requestId 7·8·1, pageNumber 2, totalPages 4, lastPage false

curl "$BASE/api/admin/requests?sortBy=id&sortOrder=asc&pageSize=3" -H "Authorization: Bearer $A"
# → 200, requestId 1·2·3

curl "$BASE/api/admin/requests" -H "Authorization: Bearer $C"
# → 403 {"message": "접근 권한이 없습니다."}

curl "$BASE/api/admin/requests?sortBy=price" -H "Authorization: Bearer $A"
# → 400 {"message": "페이지 번호, 크기 또는 정렬 조건이 올바르지 않습니다."}

curl "$BASE/api/admin/requests?status=DONE" -H "Authorization: Bearer $A"
# → 400 {"message": "경로 또는 쿼리 값의 타입이 올바르지 않습니다."}
```

SQL 로그: `service_request`에 `member`, `second_category`, `second_region`을 join한 select 1번만 나간다. 첫 페이지 결과가 pageSize보다 적으면(1·2번) Spring Data가 count 쿼리를 생략하고, 3·4번에서는 count가 1번 나간다.
