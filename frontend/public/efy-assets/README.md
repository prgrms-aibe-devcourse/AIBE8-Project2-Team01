# EFY 프론트 이미지

- 카테고리 아이콘은 기존 `icons-256/` 로컬 파일을 사용한다.
- 예시 고수는 원본 사진 한 장을 큰 카드와 원형 아바타에 공통으로 사용하며 `src/data/expertImages.json`의 Supabase 공개 URL을 사용한다.
- `categoryMeta.js`의 `expertImage()`와 `expertFace()`를 통해 모든 예시 화면에서 같은 대응을 사용한다.
- 사진은 AI로 만든 가상 인물이며 실제 고수 사진이나 작업 실적을 의미하지 않는다.
- 사진은 원본 파일과 공개 URL 응답의 바이트 일치를 확인한 뒤 로컬 사본을 제거했다. 경로·종류는 `manifest.json`에 기록한다.
- 아이콘과 브랜드 로고는 이번 사진 정리에서 제거하지 않는다.
- 실제 회원 프로필 사진과 작업 사진은 기존 API의 URL을 그대로 사용한다.
